DistroAV (formerly OBS-NDI) is a plugin for OBS Studio that adds NDI® (Network Device Interface) support, allowing you to send and receive high-quality, low-latency audio and video over your local network.

This plugin provides:
- NDI Source: Receive NDI video/audio in OBS
- NDI Output: Send OBS video/audio as NDI
- NDI Filter: Apply NDI output to individual sources
- Preview Output: Send the OBS preview as NDI
- Audio Output: Send audio to NDI
